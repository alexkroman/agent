Place the web server in us-east-2 first, where the platform database is. A durable run's journal calls are sequential by construction, so an unpinned container put ~460 ms of distance on each one — 14 calls and ~7.3 s for one 300 KB transcription, against 31.4 ms for the same calls in-region. Pinned as a FALLBACK LIST (us-east-2, then us-east-1): a bare single region is what once placed no container at all.
