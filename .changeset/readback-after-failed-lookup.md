Default voice prompt: when a lookup on a spoken value has failed and the agent finally asks the caller, it now opens by saying back exactly what it heard, spelled as an identifier ("I have M-A-R-I-A Garza, ZIP 6-0-6-1-4 — which part is off?"), so the caller can catch the one mis-heard character. The rule against reading spelled input back still holds everywhere else.
