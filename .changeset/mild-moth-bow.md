Fix nine defects a review of the durable-workflow work found, each of which is silent when wrong. A wake sweep whose catalog pre-check named only one of the two journal tables failed the union for a whole CLUSTER when any schema lacked the other, so no agent on it was ever woken again. The candidate enumeration had no cursor, so a fleet past the cap re-read its first page forever and agents sorting beyond it never resumed. A wake timer's detached `execute` carried no `catch`, turning one transient database failure into an unhandled rejection that kills a self-hosted process. `POST /workflows/runs` escaped the surface rate limit entirely, because the two limiters were selected rather than both counted. The wake request recorded a 429 from our own limiter, and a 503 from the broker, as a successful boot. `createAgentServer` forwarded the whole agent env, which enabled host mode for any agent whose env set `AAI_ALLOW_HOST`. Determinism drift was reported the moment a run rejected, so a run with concurrent steps buried a real failure under a list of invented violations. A page retried an unknown run id forever, staying busy and brokering on every read. And a blob's stored byte count ignored base64 padding, disagreeing with the bytes the run actually receives.
